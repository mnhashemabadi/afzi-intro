# افزی

[afzi.ir](https://afzi.ir) کوتاه‌کننده لینک اکوسیستم است.

یک کد کوتاه می‌گیری و afzi تو را به آدرس اصلی می‌فرستد. صفحه مقصد مال afzi نیست.

- آگهی آلور و آزادچی روی همان سایت‌ها می‌ماند.
- فاکتور و فروشگاه مال کسب‌افزار است.
- لینک سایت‌های دیگر، مثل دیوار، هم به خود همان سایت برمی‌گردد.
- همه‌جو جای کشف است، نه جای نگهداری آگهی.

تبلیغات و آمار کمپین هنوز ساخته نشده. afzi امروز فقط میانبر است.
