# افزی

افزی را ساختم تا یک نشانی بلند لینک کوتاه شود و باز کردن آن لینک همان صفحه را باز کند. صفحهٔ جدا برای مقصد نمی‌سازم. روی سایت می‌شود نشانی را کوتاه کرد، برایش تصویر QR گرفت، و اگر لازم باشد رمز یا تاریخ پایان گذاشت.

سایت: [afzi.ir](https://afzi.ir)

افزی یک وب‌سایت است.

## English

I built Afzi so a long address becomes a short link, and opening that link opens the same page. I do not build a separate page for the destination. On the site you can shorten an address, get a QR image for it, and set a password or an end date when you need one.

Site: [afzi.ir](https://afzi.ir)

Afzi is a website.
